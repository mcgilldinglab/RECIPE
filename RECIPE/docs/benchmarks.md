# Benchmarks

Benchmark wrappers are provided under `benchmarks/single_cell/`.

The benchmark code is separate from the public task reproduction commands because several baselines require external tools, external checkpoints, or files that are not distributed in this repository.

## Single-Cell RNA-Seq Benchmarks

The benchmark workflow follows the notebook-derived data export used for the manuscript, but the public wrappers below require explicit input paths and do not depend on local notebook paths.

The reusable Python wrappers included in this repository are:

- `benchmarks/single_cell/prepare_single_cell_sctranslator_data.py`
- `benchmarks/single_cell/run_single_cell_kernel_ridge_benchmark.py`
- `benchmarks/single_cell/run_single_cell_vanillann_benchmark.py`
- `benchmarks/single_cell/run_sctranslator_chunked_inference.py`

These wrappers expect explicit input paths and do not contain local absolute paths as defaults.

Install the optional benchmark dependencies with `python -m pip install -e ".[benchmarks]"`. Expression tables may use `transcript_id`, `protein_id`, or `Unnamed: 0` as the identifier column. For another name, pass `--transcript-column COLUMN`.

## scTranslator

scTranslator is not vendored into RECIPE. Use a separate scTranslator checkout and its pretrained checkpoint. The local fine-tuning command was:

```bash
CUDA_VISIBLE_DEVICES=2 torchrun --nproc_per_node=1 --nnodes=1 --node_rank=0 \
  --master_addr=127.0.0.1 --master_port=23333 \
  code/stage3_fine-tune.py \
  --epoch=100 \
  --frac_finetune_test=0.25 \
  --fix_set \
  --pretrain_checkpoint=/path/to/scTranslator/checkpoint/stage2_single-cell_scTranslator.pt \
  --RNA_path=/path/to/X_train_genes_adatas12.h5ad \
  --Pro_path=/path/to/Y_train_protein_adatas12.h5ad
```

After fine-tuning, run RECIPE's wrapper:

```bash
python benchmarks/single_cell/run_sctranslator_chunked_inference.py \
  --repo-root /path/to/scTranslator \
  --checkpoint /path/to/fine_tuned_sctranslator.pt \
  --base-checkpoint /path/to/scTranslator/checkpoint/stage2_single-cell_scTranslator.pt \
  --data-dir outputs/benchmarks/sctranslator_inputs \
  --seed 12 \
  --device cuda:0 \
  --output-dir outputs/benchmarks/sctranslator
```

The upstream fine-tuning script saves model weights rather than a complete model object, so `--base-checkpoint` supplies the architecture used to load those weights. It may be omitted only when `--checkpoint` already contains a complete PyTorch model.

## KRR And VanillaNN

The examples below use `NC3` as the target protein column because that is the name in the manuscript table. Replace it with the protein column in your own input file.

Run KRR:

```bash
python benchmarks/single_cell/run_single_cell_kernel_ridge_benchmark.py \
  --expression-csv data/single_cell/expression_normalized.csv \
  --protein-map-csv /path/to/protein_map.csv \
  --bulk-table-csv data/bulk/human_reference.csv \
  --protein-column NC3 \
  --seed 12 \
  --output-dir outputs/benchmarks/krr
```

Run VanillaNN:

```bash
python benchmarks/single_cell/run_single_cell_vanillann_benchmark.py \
  --expression-csv data/single_cell/expression_normalized.csv \
  --protein-map-csv /path/to/protein_map.csv \
  --bulk-table-csv data/bulk/human_reference.csv \
  --protein-column NC3 \
  --seed 12 \
  --device cuda:0 \
  --output-dir outputs/benchmarks/vanillann
```

## C10 Figure Source

`c10_best_on_c10_test.pdf`, `svec_best_on_svec_test.pdf`, and the C10/SVEC cross-condition scatter plots were generated by the Module D scRNA-seq branch, not by scTranslator or the scRibo-seq branch. These figures evaluate the nanoSPINS cell-graph checkpoints `phase3_nanospins_best.pth` from the archived C10/SVEC phase3 runs. Use `scripts/run_module_d.py --assay scrnaseq --scrnaseq-reproduction-preset phase3_c10_svec_test_scatter` to recreate them from the archived phase23 artifacts.
